# PdfdirWin

下载链接[Release](https://github.com/xiaochuan-dev/pdfdir-win/releases)

Windows平台为PDF文件添加目录的工具，灵感来源于[chroming/pdfdir](https://github.com/chroming/pdfdir)

与[chroming/pdfdir](https://github.com/chroming/pdfdir)的区别

| 特点 |本项目 | [chroming/pdfdir](https://github.com/chroming/pdfdir) |
|----|----|----|
|源码 | c# | python |
| 处理大的目录速度 | 速度较快 | 速度不如本项目 |
| 支持写回原PDF文件 |支持 | 不支持 |
| 支持自定义解析目录文本 | 不支持 | 支持 |
